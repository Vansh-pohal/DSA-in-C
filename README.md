## 🧠 Merge Sort

Merge Sort is a **divide-and-conquer** sorting algorithm.

It works by:

1. Dividing the array into two halves.
2. Recursively dividing the halves until each part contains one element.
3. Merging the smaller sorted arrays together.
4. Copying the sorted elements back into the original array.

### Time Complexity

| Case    | Complexity   |
| ------- | ------------ |
| Best    | `O(n log n)` |
| Average | `O(n log n)` |
| Worst   | `O(n log n)` |

### Space Complexity
